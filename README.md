## 📖 Tentang Proyek

**IndoInves** adalah platform digital berbasis web yang dirancang untuk membantu pengguna Indonesia dalam merencanakan investasi, mengelola keuangan, mengakses kalkulator finansial, serta memantau simulasi saham dan kripto secara interaktif dan mudah diakses. Proyek ini bersifat *open-source* dan terus dikembangkan bersama komunitas.

---

## 🛠️ Fitur & Daftar Tools

Platform ini menyediakan berbagai perangkat bantu interaktif (*tools*):
- 📈 **[Simulator Saham](https://indoinves.github.io/tools/simulatorsaham.html)**: Simulasi transaksi dan portofolio saham.
- 🪙 **[Simulator Kripto & Pro](https://indoinves.github.io/tools/simulatorkripto.html)**: Analisis dan simulasi pasar aset kripto.
- 💰 **[Kalkulator Investasi](https://indoinves.github.io/tools/investasi.html)**: Hitung proyeksi pertumbuhan aset dan bunga majemuk.
- 🏦 **[Bank Locator](https://indoinves.github.io/tools/banklocator.html)**: Peta dan direktori lokasi perbankan terdekat.
- 📝 **[Content Blog & Artikel](https://indoinves.github.io/tools/contentblog.html)**: Berita dan edukasi finansial terkini.
- 🌐 **[Website & Tech Tools](https://indoinves.github.io/tools/website.html)**: Perangkat penunjang digital.

## ⚙️ Cara Membangun (Build) & Menjalankan

Karena proyek ini menggunakan teknologi web statis standar (HTML, CSS, dan JavaScript), Anda dapat menjalankannya dengan mudah di komputer lokal:

1. **Clone repository ini:**
```bash
git clone [https://indoinves.github.io.git](https://indoinves.github.io.git)

```


2. **Masuk ke direktori proyek:**
```bash
cd indoinves.github.io

```


3. **Jalankan server lokal (opsional, misal menggunakan Python):**
```bash
python -m http.server 8000

```


4. **Buka browser:**
Akses `http://localhost:8000` di browser favorit Anda.
